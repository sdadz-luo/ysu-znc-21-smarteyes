## 主板（上板 + 下板）

采用分体式设计：**下板**承担供电与电源开关，**上板**负责信号与交互，以缓解单板布局压力（技术报告 3.3 节）。

### 上板 · 主控页

MIMXRT1064DVL6A 的全部功能引脚网络引出，主要网络分组：

- 编码器：`LSB1`–`LSB4` / `DIR1`–`DIR4`（四路正交解码）
- 电机：`PWM1-PH/EN` – `PWM4-PH/EN`
- 陀螺仪：`MPU_SCL` / `MPU_SDA` / `MPU_SDO` / `MPU_CS`
- 屏幕：`TFT_SCL` / `TFT_SDA` / `TFT_RES` / `TFT_DC` / `TFT_CS` / `TFT_BLK`
- 无线串口：`WIRELESS_TX` / `WIRELESS_RX` / `WIRELESS_RTS`
- 按键：`KEY0`–`KEY4`（五向）
- 摄像头：`CAMRX1/TX1`、`CAMRX2/TX2`（UART 型视觉模块）
- 其他：`BUZZER`

### 上板 · 接口页

| 功能块        | 接口/器件                                       |
| ------------- | ----------------------------------------------- |
| 速度编码器 ×4 | HC-JN254-2-03-Z                                 |
| 电机 ×2       | HC-JN254-2-04-Z（每路 PH/EN 各一）              |
| 陀螺仪        | XH2.54-WS-8P                                    |
| TFT 屏幕      | 8 pin 排针（SCL/SDA/RES/DC/CS/BLK）             |
| 无线串口      | WIRELESS_RX/TX/RTS                              |
| 五向按键      | KEY0–KEY4 + SW7 复位                            |
| 蜂鸣器        | Q4 MMS5050-H-TP（NPN 驱动）                     |
| 负载开关 ×2   | SY6280AAAC（`5V_BUCK`、`3V3_LDO` 两路受控输出） |

### 下板 · 电源页

- **12V→5V**：MP2315 Buck（4.7 µH 储能电感，R3/R4/R5 反馈网络，C9+R5 补偿，R2+C5 自举）
- **5V→3.3V**：TLV1117LV33 LDO
- **主板开关 / 电驱开关**：HY19P03D3 高侧 PMOS + MT0-102 拨动开关 + BZT52C16 稳压管，`12V` 与 `MOTOR` 两路独立控制
- **电驱电源**：NCE6045G NMOS + XT30 接口（`CON1`/`CON2`）
- **电源指示灯**：LED1（MOTOR）、LED4（3V3_LDO）、LED5（5V_BUCK）
- 预留 `5V_BUCK` / `3V3_LDO` 排针（H1）与共地口（H5）

## 电驱板

单个驱动模块内含两路独立 H 桥，最多驱动四路有刷电机中的两路，整车使用两块。

- **前级信号缓冲**：SN74HC125PWR 四路三态缓冲器，输入端 10 kΩ 下拉，避免上电瞬间 PWM 悬空导致误动作
- **栅极驱动**：HIP4082IBZT ×2（自举二极管 1N5819WS + 1 µF/4.7 µF 自举电容）
- **功率级**：TM60N02D N-MOSFET ×8，构成两路 H 桥，每颗栅极串 10 Ω 抑制开关振荡
- **供电**：XT30（`U14`，XT30U-M-G.B）+ 470 µF 电解电容；电机输出 XT30（`CN2`/`CN3`）
- **其他**：SS12D07VG3 拨动开关、方向指示灯 LED1
